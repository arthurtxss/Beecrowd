# Beecrowd - Python

## Descrição

Repositório contendo uma **série de exercícios de prática em sintaxe e lógica de programação** utilizando Python. 

Este projeto foi criado para documentar e compartilhar soluções de problemas resolvidos na plataforma [Beecrowd](https://www.beecrowd.com.br/), focando no desenvolvimento e aperfeiçoamento de habilidades fundamentais em programação.

## Objetivo

O principal objetivo deste repositório é:

- 📚 Praticar e consolidar conhecimentos em **Python**
- 🧠 Desenvolver **raciocínio lógico** e habilidades de resolução de problemas
- 💻 Aperfeiçoar **sintaxe** e boas práticas de programação
- 📖 Servir como referência e portfólio de exercícios resolvidos

## Estrutura

Os exercícios estão organizados por dificuldade e tema, com cada solução acompanhada de comentários explicativos para melhor compreensão da lógica utilizada.

## Tecnologias

- **Linguagem**: Python 3.x
- **Plataforma**: Beecrowd

## Como Usar

1. Clone este repositório:
   ```bash
   git clone https://github.com/arthurtxss/Beecrowd.git
   ```

2. Navegue até o diretório desejado e execute o arquivo Python:
   ```bash
   python nome_do_arquivo.py
   ```
